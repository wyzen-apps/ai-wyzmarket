# Étape : triage

Capacités : `exploration`
Rules : aucune
Exécutant : orchestrateur
Entrée : description du bug
Procédure :
1. Localiser la zone par une lecture ciblée.
2. Complexe si : plusieurs modules, contrat d'API, schéma de base, sécurité ou droits, ou cause
   inconnue après lecture ; sinon simple.
Sortie attendue : `simple` ou `complexe` et la raison, au journal
Gate : classement noté
